# 0.1.14 2026-11-06

## English

### New
- ElyDoc: a toolbar above the page: Undo, Redo, font, size, bold, italic, underline, strikethrough, alignment, bullets and numbering (#67).
- ElyDoc: Mail Merge reads XLSX, XLS and ODS as well as CSV (#67).
- ElyDoc: with the Chinese interface, new documents use Chinese Word's defaults: a two-character tab stop and compressed punctuation (#61).
- ElyMail: QQ Mail, 163 and 126 presets with their servers filled in and a guide to the authorization code; ElyMail names itself to servers that ask (IMAP ID), which NetEase requires (#25, #69).
- ElyMail: select and copy text in a message, Select All in the body, copy a link's address, and copy or save a picture from the right-click menu (#68).
- ElyPDF: page controls above the page, and each PDF reopens where you left it, with its zoom, rotation and side panel (PR #65, thanks OmarGonD).

### Fixes
- ElyPDF: some PDFs, often books with bookmarks, failed with “expected value at line 1 column …” (#66, #73).
- ElyPDF: a crop or inserted page outside the allowed page sizes is refused without losing your redo.
- ElyDoc: changing the font size on an empty line showed an error and did nothing (#62).
- ElyMark: Enter in the find box steps to the next match and keeps the cursor in the box; Esc puts it on the match (#60).
- ElyMark: formulas ending in `$$` on the same line show as formulas, read as GitHub reads them (#63).
- ElyMail: the message list's scrollbar no longer flickers while you hold it.
- ElyMail: sent HTML now matches what the compose box shows: bare web addresses become links, and emoji shortcodes become emoji.
- Windows: the app reports an error and exits when its window cannot open, instead of crashing or hanging.
- Windows: the document engine no longer refuses to start on machines that start programs DPI-aware.

### Engineering
- Pull-request CI passes every step again: a dependency advisory had stopped it at `deny.sh`, so clippy, the panic table and the engine-free tests were skipped. pulldown-cmark 0.13.6 and async-executor 1.14.1 clear it.
- All four platforms ran the whole test suite with engines required before packaging; 0.1.14 was rebuilt until every test passed on each.
- The README build packages were checked again in clean Ubuntu 24.04, Fedora 44 and Arch containers.
- The Linux release job moved to its own WSL runner and no longer waits for Windows.
- The comment checker reads HTML inside SVG and MathML correctly; five nesting cases remain (partly done).
- ElyPDF's Linux certificate check compares names as RFC 4518 says; its last fix is not yet reviewed (partly done).
- ElyTree opens a terminal and stops Git on Windows and Linux.
- Unsupported XLSX functions keep their cached results through a save.
- Gpui-pre 0.3.11; the vendored gpui fixes were replayed onto it and the component library pin moved forward.
- PDF edits that would leave a page outside the allowed size are refused before anything changes, so redo survives.
- MacOS accessibility review covers all seven first-batch apps, ElyMail included.
- Task records match their last review verdicts; `records.py` checks it.
- Closing a window while a tab saves, or after its tab closed, no longer freezes the session list.

## 中文

### 新功能
- ElyDoc：页面上方加了工具栏：撤销、重做、字体、字号、粗体、斜体、下划线、删除线、对齐、项目符号与编号（#67）。
- ElyDoc：邮件合并除 CSV 外也读 XLSX、XLS、ODS（#67）。
- ElyDoc：界面为中文时，新建文档照中文 Word 的默认：制表位两个字、压缩标点（#61）。
- ElyMail：QQ 邮箱、163、126 的预设，服务器已填好，并说明怎样生成授权码；服务器要求时报上客户端名（IMAP ID，网易邮箱需要）（#25、#69）。
- ElyMail：邮件正文可选中复制、全选，右键可复制链接地址，图片可复制或另存（#68）。
- ElyPDF：页面上方的翻页控件；每个 PDF 重开时回到上次的位置、缩放、旋转与侧栏（PR #65，感谢 OmarGonD）。

### 修复
- ElyPDF：部分 PDF（多为带书签的书）报“expected value at line 1 column …”打不开（#66、#73）。
- ElyPDF：裁剪或插页超出页面大小时被拒，且不丢失可重做的操作。
- ElyDoc：空行上改字号报错且改不了（#62）。
- ElyMark：查找框里回车跳到下一处，光标留在查找框；Esc 落到当前这一处（#60）。
- ElyMark：结尾的 `$$` 与公式同行时照 GitHub 的读法显示为公式（#63）。
- ElyMail：按住邮件列表的滚动条时不再闪烁。
- ElyMail：发出的 HTML 与写信框所见一致：裸网址成链接，表情短码成表情。
- Windows：窗口打不开时报错退出，不再崩溃或卡住。
- Windows：在默认以 DPI 感知启动程序的电脑上，文档引擎不再启动即被拒。

### 工程
- 合并前 CI 重新全部通过：此前一条依赖安全公告让它停在 `deny.sh`，clippy、panic 表与不需引擎的测试都被跳过；升级 pulldown-cmark 0.13.6、async-executor 1.14.1 后解除。
- 四端打包前都以“必须有引擎”跑完整测试；0.1.14 重建到每一端全部通过才发。
- README 列的构建依赖在干净的 Ubuntu 24.04、Fedora 44、Arch 容器里重新核过。
- Linux 发布任务改到自己的 WSL runner，不再排在 Windows 之后。
- 注释检查正确读 SVG、MathML 里的 HTML；还余五种嵌套（部分完成）。
- ElyPDF 在 Linux 上照 RFC 4518 比较证书名；末轮之修尚未审查（部分完成）。
- ElyTree 在 Windows、Linux 上也能打开终端、停止 Git。
- XLSX 里不支持的函数，保存后缓存值不丢。
- 升到 gpui-pre 0.3.11，vendor 里的 gpui 修复重放其上，组件库 pin 跟上。
- 会使页面超出允许尺寸的 PDF 编辑在改动前即被拒，重做不丢。
- MacOS 无障碍复核覆盖首批七个应用，含 ElyMail。
- 任务记录与末轮审查结论一致，由 `records.py` 核对。
- 标签保存中或已关闭时关窗，会话列表不再卡住。
