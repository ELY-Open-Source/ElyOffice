# 0.1.4 2026-10-12

## English

- Windows: paths show in their plain form, without a `\\?\` prefix.
- Zoom with Ctrl and the wheel (Cmd on macOS) in ElyDoc, ElyTable, ElyShow, ElyPDF and ElyMark, one step per notch. It used to be the Windows or Super key, which Hyprland takes on Linux.
- The pointer follows the document: an arrow over cells, a text cursor in text, a resize pointer on borders and a hand on links.

## 中文

- Windows：路径以普通形式显示，不带 `\\?\` 前缀。
- ElyDoc、ElyTable、ElyShow、ElyPDF、ElyMark 可按住 Ctrl 滚动滚轮缩放（macOS 为 Cmd），一格一档。原先要按 Windows 键或 Super 键，后者在 Linux 的 Hyprland 上被占用。
- 指针随文档变化：单元格上是箭头，文字里是文字指针，边线上是调整指针，链接上是手形。
