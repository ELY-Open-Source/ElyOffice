# 0.1.16 2026-11-12

## English

### New
- Drop files on any Ely window to open them: files of this app's type open here, others open in the Ely app for their type (#75).
- Linux: one `ely-office` package (deb, rpm, Arch) installs every app with a single shared document engine (#77, #42).
- Windows: opening a file shows a splash at once while Windows scans the app, and Open With lists each app by its own name.
- ElyPDF: New opens a blank page on the paper size you pick (#80).
- ElyDoc: the first-line indent is set in characters, as Chinese text wants (#76).
- ElyDoc: a screen reader gets the whole body and follows the caret through it.
- ElyTree: a toggle hides the history graph, the detail panes drag on both axes, and commit details and lists select and copy by drag (PR #70, #71, #72).
- Updates are checked through the site's relay when GitHub cannot be reached.
- ElyTable: R code you have not seen asks before it runs, on the first run and after a file is opened.

### Fixes
- ElyShow: PowerPoint decks no longer put a gap between Chinese or Japanese text and Latin text (#83).
- Fonts are found by their family name in any language; Source Han Serif is no longer reported missing (#82). A missing font now names the font drawn in its place.
- Pictures dropped on a page go in where they fall (#81).
- Windows: a cold start no longer holds the new window empty while the engine starts, and ElyTable and ElyShow no longer load the word processor before a file opens (#79).
- ElyMail: sync failures, an expired sign-in and TLS errors are worded in your language (#48).
- ElyMark: a `$$` inside code, a link or image address, an image's alt text or an HTML tag no longer swallows the formula after it (#63).
- ElyTable: a new chart lands beside its data, clear of other charts and drawings, also on right-to-left sheets.
- ElyTable: when a linked workbook loses the sheet a formula reads, Update Links names the file and keeps the saved values.
- ElyDoc: removing a tab stop removes the one shown; mixed colors and sizes in a selection show as mixed; Word's EQ fields with no lowering amount lower by two points and their cached result is not drawn twice.
- ElyDoc: Mail Merge reads two spreadsheets at once without mixing their rows.
- ElyPDF: moving a text block leaves tagged points where they were; removing an annotation also removes its structure references; signing waits until a Save As is complete.
- ElyShow: exporting the current slide exports the slide on screen.
- ElyShow: Ctrl+Home after the first typed letter moves the caret; a replace in a text box keeps your typing.
- A file opened with a password is saved with it.
- macOS: apps start about 50 ms sooner.

### Engineering
- Released 5 days after 0.1.15: the PowerPoint text gap (#83) and the second round of fixes were ready, and the user asked for a release now.
- 3 fixes were made after their last review failed and have not been reviewed again; their review needs a Windows machine with Microsoft Office.
- 20 tasks used up their review rounds; their latest fixes are recorded in `tasks/TASKS.md` and are not reviewed.
- A release builds only past its gates: notes that count unreviewed fixes and explain a short gap, a benchmark of this version on each system, and a passing `pr.yml` on the commit.
- The comment checker reads HTML with parse5, as browsers read it.
- Dependency advisories cleared: rusqlite 0.41 and rustix 1.1.6; the site pins undici 7.30.2.
- Kernel patches 0111 to 0131; `patches/UPSTREAM.md` lists the upstream defects they fix; kernel patch logs reach the app log; the engine no longer registers a DDE service.
- The vendored gpui is the crates.io release plus patches, checked by a script.

## 中文

### 新功能
- 把文件拖到任一 Ely 窗口即打开：本应用的类型在本窗口打开，其他类型交给对应的 Ely 应用（#75）。
- Linux：新增 `ely-office` 合集包（deb、rpm、Arch），装上全部应用，共用一份文档内核（#77、#42）。
- Windows：打开文件时立刻显示启动画面，不必干等系统扫描应用；“打开方式”里每个应用显示自己的名字。
- ElyPDF：新建时按所选纸张打开一张空白页（#80）。
- ElyDoc：首行缩进以字符为单位，适合中文排版（#76）。
- ElyDoc：屏幕阅读器能读到整篇正文，并随光标移动。
- ElyTree：可以隐藏历史图；详情的分隔条可横竖拖动；提交详情和各列表可拖选复制（PR #70、#71、#72）。
- 连不上 GitHub 时，经官网转发检查更新。
- ElyTable：没看过的 R 代码，第一次运行和打开文件后运行前都会先询问。

### 修复
- ElyShow：PowerPoint 演示文稿里中日文与西文之间不再多出空隙（#83）。
- 字体以任何语言的家族名都能找到，思源宋体不再报缺失（#82）；缺字体时会写明用哪种字体代替。
- 拖到页面上的图片落在松手的位置（#81）。
- Windows：冷启动时新窗口不再一直空白等内核；ElyTable 与 ElyShow 打开文件前不再先载入文字处理模块（#79）。
- ElyMail：同步失败、登录过期与 TLS 错误按界面语言说明（#48）。
- ElyMark：代码、链接或图片地址、图片替代文字、HTML 标签里的 `$$` 不再吃掉其后的公式（#63）。
- ElyTable：新图表放在数据旁，避开别的图表和绘图对象，从右到左的工作表也一样。
- ElyTable：链接的工作簿里公式所读的工作表不见了时，“更新链接”会点名该文件，并保留保存的值。
- ElyDoc：删除制表位删的是显示的那一个；选区里颜色、字号不一时显示为混合；Word 的 EQ 域省略降低量时降 2 磅，其缓存结果不再重复显示。
- ElyDoc：邮件合并同时读两个表格，行不会串。
- ElyPDF：移动文字块时，标记点留在原处；删除批注时一并删除结构树对它的引用；“另存为”完成前不签名。
- ElyShow：导出当前幻灯片导出的是屏幕上那一张。
- ElyShow：打出第一个字后按 Ctrl+Home 光标会移动；在文本框里替换时保留刚打的字。
- 带密码打开的文件，保存时仍带密码。
- macOS：应用启动快约 50 毫秒。
