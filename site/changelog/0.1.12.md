# 0.1.12 2026-10-26

## English

### New
- ElyTable: other programs, scripts and AI agents among them, read and write cells of an open workbook and save it from the command line: `ely-table cell docs`, `get`, `set`, `save`. Addresses name their sheet, as in `Sheet1!A1`; reads and writes leave your cursor and selection alone, and each write is one undo step (#19).
- ElyPDF: View › Horizontal Scrolling lays pages in a row; Shift and the wheel move across (#39).
- ElyMark: right-click a tab, a file in the folder, or a recent file to Copy File Name or Copy Path (#41).
- Settings › Storage › Data folder: keep your data in a folder you choose, such as another drive. It moves there at the next start with no other Ely app open; after a system reinstall, choose the same folder and Ely uses it as it is (#43).

### Fixes
- ElyMark: on Windows the outline's scroll bar flickered and would not drag (#36).
- ElyPDF: on Windows a save over the open file failed (Access is denied); signature certificates are now checked for trust on Windows and Linux too, not only macOS.
- Spell checking works on Windows and Linux; on Windows, screen readers follow the caret and the selection.
- ElyMark: searching a large folder is faster (#40).

## 中文

### 新功能
- ElyTable：别的程序（脚本、AI 代理）可经命令行读写已打开工作簿的单元格并保存：`ely-table cell docs`、`get`、`set`、`save`。地址写明工作表，如 `Sheet1!A1`；读写不动你的光标与选区，每次写入是一步撤销（#19）。
- ElyPDF：“视图 › 横向滚动”，页面排成一行，按住 Shift 滚动滚轮横移（#39）。
- ElyMark：右键标签、文件夹里的文件或最近文件，可“复制文件名”“复制路径”（#41）。
- 设置 › 存储 › 数据文件夹：数据可放到自选的文件夹（如另一块盘），下次启动、没有别的 Ely 应用开着时搬过去；重装系统后选回同一文件夹即直接使用（#43）。

### 修复
- ElyMark：Windows 上大纲的滚动条闪烁、拖不动（#36）。
- ElyPDF：Windows 上存不回已打开的文件（拒绝访问）；签名的证书信任在 Windows 与 Linux 上也做核对（原只 macOS）。
- Windows 与 Linux 上拼写检查可用；Windows 上读屏软件跟得上插入点与选区。
- ElyMark：在大文件夹里搜索更快（#40）。
