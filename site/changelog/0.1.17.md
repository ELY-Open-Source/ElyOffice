# 0.1.17 2026-11-19

## English

### New
- One installer per platform holds every app: on Windows a single setup with a checkbox per app, on macOS a `.pkg`, on Linux one `ely-office` package and one AppImage. An update replaces the whole set.
- Resident engines: after you sign in, each installed document app (ElyDoc, ElyTable, ElyShow) keeps an idle engine ready, so a double-clicked file skips the engine start. It uses no CPU while it waits (on Windows, apart from the system's own timed reports), and fewer or none are kept on machines with little memory. `ely-doc engine` starts one and `ely-doc engine stop` ends it.
- Apps open with a short launch animation that stays until the document is drawn, and stays still when Reduce Motion is on.
- Closing a window or tab no longer waits for the engine.
- Banners are gone, except ElyDoc's missing-font notice: their news moves to the status bar, to a dialog when it has consequences, or to an error page.
- ElyTable: the format panel sets a cell's font and size (#86).
- ElyPDF: the scroll bar drags straight through the document (#84).
- ElyMark: the document text size has its own row in Settings, with a reset (#85); a folder found by search opens to show its files (#87).
- ElyShow: dragging a shape, text box or picture shows guides when its edges or centre line up with other objects or the slide, and snaps to them and to equal spacing; Alt drags freely.

### Fixes
- Chinese text whose font is not installed no longer turns into brush or handwriting faces in ElyDoc, ElyTable and ElyShow; it takes the language's default serif or sans font.
- ElyShow: after inserting a shape from the Insert menu, the next click selects instead of drawing another shape.
- ElyShow on Linux: the slideshow window takes the keyboard when it opens, so the arrow keys, Page Up, Page Down and Space turn slides.
- ElyMail: a narrow sidebar keeps each account's unread count in view (#88).
- ElyPDF: saving no longer makes files grow; new streams are compressed and new fonts are subset.
- ElyMark: a PDF export with Chinese text embeds only the characters used, not the whole font, and Japanese text in an exported PDF copies out in full.
- ElyDoc: what Word cached inside an EQ field (nested fields, text boxes, pictures, notes) no longer leaks into the document.
- Pasted HTML pictures are decoded and checked before the engine gets them.
- The apps talk to their engine over a channel only your user account can open, and check its version before using it.

### Engineering
- Released 6 days after 0.1.16: fixes the user reported were ready: Chinese fonts drawn in brush faces, slideshow keys that did nothing, dragging objects in ElyShow, and an extra shape drawn after inserting one.
- 3 fixes were made after their last review failed and have not been reviewed again (R15.11, R15.11c, R15.11g); their review needs a Windows machine with Microsoft Office.
- 33 tasks used up their review rounds or wait on something outside the project; each is marked `[!]` in `tasks/TASKS.md` with what is left.
- Dragging objects in ElyShow needs kernel patch 0140; it is tested on Linux and macOS, not yet by hand on Windows. The slideshow keys were fixed for the case reproduced here; the conditions of the user's report were not reproduced.
- Kernel patches 0132 to 0145, MuPDF patches 0009 to 0011, gpui-pre 0.3.12 with patch 0014.
- No arm64 builds for Linux or Windows.

## 中文

### 新功能
- 每个平台一个安装包，装全部应用：Windows 一个安装程序，每个应用一个勾；macOS 一个 `.pkg`；Linux 一个 `ely-office` 包和一个 AppImage。更新整套替换。
- 常驻引擎：登录后，每个装了的文档应用（ElyDoc、ElyTable、ElyShow）各有一个空闲引擎等着，双击文件不必再起引擎。等待时不占 CPU（Windows 上系统库的定时上报除外）；内存少的机器少留或不留。`ely-doc engine` 起一个，`ely-doc engine stop` 让它退出。
- 应用启动时有一段简短的动画，留到文档画出；开着“减少动效”时静止。
- 关窗口、关标签不再等引擎。
- 横幅去掉了，只留 ElyDoc 的缺字体提示：其余信息改在状态栏、有后果时的对话框或错误页里说。
- ElyTable：格式面板可设单元格的字体与字号（#86）。
- ElyPDF：滚动条可一直拖过整份文档（#84）。
- ElyMark：设置里有文档字号一行，可重置（#85）；搜索找到的文件夹可展开，看到其下的文件（#87）。
- ElyShow：拖动形状、文本框、图片时，边或中线与别的对象、幻灯片对齐即画出参考线并吸附，等距也吸附；按住 Alt 不吸附。

### 修复
- 文档点名的中文字体本机没有时，ElyDoc、ElyTable、ElyShow 不再画成毛笔、手写一类的字体，改取该语言默认的宋体类或黑体类。
- ElyShow：从“插入”菜单插入形状后，下一次点按是选中，不再多画一个形状。
- ElyShow（Linux）：放映窗口打开即拿到键盘，方向键、Page Up、Page Down、空格都能翻页。
- ElyMail：侧栏变窄时仍看得到各账户的未读数（#88）。
- ElyPDF：保存后文件不再变大；新写的流压缩，新嵌的字体取子集。
- ElyMark：含中文的 PDF 导出只嵌所用的字，不再嵌整个字体；导出的日文 PDF 能完整复制出文字。
- ElyDoc：Word 存在 EQ 域缓存里的东西（嵌套域、文本框、图片、注）不再混进文档。
- 粘贴 HTML 里的图片先解码、核对再交给引擎。
- 应用与引擎之间改用只有本用户能连的通道，用前先核对版本。

### 工程
- 距 0.1.16 六天即发布：用户报的几处修好了：中文字体画成毛笔字、放映时按键不翻页、ElyShow 拖动对象、插入形状后多画一个。
- 有 3 处修复是末轮审查不过之后改的，尚未复审（R15.11、R15.11c、R15.11g），复审要一台装有 Microsoft Office 的 Windows。
- 33 条任务用完了审查轮次或卡在外部，在 `tasks/TASKS.md` 里标 `[!]`，各写明余下的事。
- ElyShow 拖动对象要内核补丁 0140，已在 Linux 与 macOS 上测过，Windows 上尚未手试。放映按键修的是本地复现到的情形，用户报告里的条件未能复现。
- 内核补丁 0132 至 0145，MuPDF 补丁 0009 至 0011，gpui-pre 0.3.12 与补丁 0014。
- Linux 与 Windows 都不出 arm64 版。
