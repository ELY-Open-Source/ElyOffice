# 0.1.6 2026-10-16

## English

### New
- One installer for all six apps. On macOS one disk image holds the six apps; drag in the ones you want. On Windows one installer lets you tick the apps to install. The single-app downloads stay.
- Printing on Windows and Linux (#3): Windows uses the system print dialog, Linux the desktop's print portal.

### Fixes
- ElyDoc no longer reports a font as missing when it is installed and in use, such as SimSun (#4).
- ElyPDF no longer calls a PDF damaged because it names a font it does not embed (#5).
- On Windows and Linux, the settings window no longer shows a second row of app menus (#6).
- ElyMark: a block you click keeps its size, weight and place while you edit it.

## 中文

### 新功能
- 六个应用合一的安装包。macOS 一个磁盘映像装着六个应用，拖入想要的即可；Windows 一个安装程序，勾选要装的应用。单个应用的下载照旧。
- Windows 与 Linux 上可以打印（#3）：Windows 用系统的打印对话框，Linux 用桌面的打印门户。

### 修复
- ElyDoc 不再把已安装、正在用的字体（如宋体）报为缺失（#4）。
- ElyPDF 不再因 PDF 用了未嵌入的字体就说文件已损坏（#5）。
- Windows 与 Linux 上，设置窗口不再多出一行应用菜单（#6）。
- ElyMark：点开的块在编辑时保持原来的大小、粗细与位置。
