# 0.1.18 2026-11-26

## English

### New
- ElyDoc: format painter (copy formatting), clear formatting, step font size up or down, change case and paragraph shading (#97).
- ElyDoc: insert symbols, text boxes and basic shapes (#98); add and remove watermarks (#99).
- ElyDoc: export as Markdown and open the result in ElyMark (#105).
- ElyDoc: commented text is highlighted on the page, with the selected comment's text darker, including inside tables (#118).
- Bundled fonts: Roboto, Open Sans, Montserrat, Lato, Source Sans 3, Inter, Noto Sans SC and Noto Serif SC; Chinese font names such as 宋体 and 黑体 map to them (#101, #102, #104).
- ElyTable: border line style, width and colour (#108); copied cells show a dashed outline (#109).
- Command line for scripts and AI agents (#107): every app answers `docs`, `open`, `new`, `export` and `save`, with single-step undo and untouched cursors; `ely-table` reads and writes cells and ranges, sets formats, and manages sheets, rows, columns, sizes, freezing and merges.
- Command line (#107): `ely-doc` gets text (also as JSON), replaces, appends, formats matches and inserts tables or pictures; `ely-show` lists, adds, duplicates, deletes and moves slides, sets text and notes, and inserts pictures; `ely-mark` sets and appends text.
- ElyMark: load web images on demand via View › Load Web Images or an image's right-click menu, or automatically when turned on in Settings › Documents; off by default, through the system proxy (#120).
- ElyMark: Find highlights every match, centres each jump and marks matching lines at the side (#92).
- ElyPDF: two-page view adds a Separate Cover Page option (#113); in single-page view, scrolling past a page edge turns the page, and arrow keys work in every view (#114).
- ElyPDF: the page list has a scroll bar (#84).
- macOS: files an Ely app opens show a document icon with that app's mark in Finder when that app is set to open them (#119).

### Fixes
- Missing Word fonts draw in the nearest free font of like width on Linux (#100); Aptos and Arial Nova draw in a sans font of like width (#110).
- ElyDoc: the font size box's arrows step by one point (#106), and the box stays blank when the selection mixes sizes (#112).
- ElyDoc: long Word files become usable once their first pages are laid out, instead of waiting for the whole file (#111).
- ElyDoc: sentence case starts a new sentence after every full stop.
- ElyDoc: with track changes on, Replace All and `ely-doc text replace` no longer write into text already deleted (#121).
- Scroll bars no longer cover content.
- ElyMark: a Find match late in a long table cell scrolls into view (#93).
- ElyMail: a message opened under a filter such as Unread stays in the list until the filter changes (#95); one address on two incoming servers counts as two accounts (#96).
- ElyMail on Windows: with fonts such as IBM Plex Sans, descenders (g, y) are no longer clipped, and unread counts sit centred in their badge.
- Office files save faster by storing pictures without recompressing them (#115); on Linux, large pictures redraw faster (#116).
- Start helpers (`ely-doc-start`, etc.) exit with the app's error code; apps read your login name from the system; single-window apps open the file when given `--new-window`.
- ElyTable: border style and width menus have names for screen readers.
- Dependency security advisories cleared (`cookie` 0.18.3, `url` 2.5.9).

## 中文

### 新功能
- ElyDoc：格式刷、清除格式、增大/缩小字号、更改大小写与段落底纹（#97）。
- ElyDoc：插入符号、文本框与基本形状（#98）；添加与移除水印（#99）。
- ElyDoc：可导出为 Markdown 并在 ElyMark 中打开（#105）。
- ElyDoc：批注对应的正文在页面上高亮显示，选中批注时颜色更深，表格内同样生效（#118）。
- 内置字体：Roboto、Open Sans、Montserrat、Lato、Source Sans 3、Inter、Noto Sans SC 与 Noto Serif SC；宋体、黑体等中文字体名会映射到它们（#101、#102、#104）。
- ElyTable：边框支持线型、线宽与颜色（#108）；复制的单元格显示虚线框（#109）。
- 面向脚本与 AI 代理的命令行（#107）：各应用均支持 `docs`、`open`、`new`、`export` 与 `save`，每次修改一步撤销且不动光标；`ely-table` 可读写单元格与区域、设格式，管理工作表、行列、尺寸、冻结与合并。
- 命令行（#107）：`ely-doc` 可读正文（含 JSON）、替换、追加、设匹配格式并插表插图；`ely-show` 可增删改移幻灯片、写正文与备注并插图；`ely-mark` 可替换全文与追加文字。
- ElyMark：可通过“视图”菜单或图片右键菜单的“加载网络图片”手动加载，也可在“设置 › 文档”开启“自动加载网络图片”；默认关闭，走系统代理（#120）。
- ElyMark：查找高亮全部匹配，跳转时滚到视野中间，并在行侧标出位置（#92）。
- ElyPDF：双页视图新增“单独显示封面”（#113）；单页视图滚过页边即翻页，各视图均支持方向键（#114）。
- ElyPDF：页面列表有了滚动条（#84）。
- macOS：由 Ely 应用打开的文件在访达里显示带有该应用标记的文档图标（#119）。

### 修复
- Linux 上缺失的 Word 字体改用宽度相近的免费字体绘制（#100）；Aptos 与 Arial Nova 改用宽度相近的无衬线字体绘制（#110）。
- ElyDoc：字号框上下箭头每次增减 1 磅（#106）；选区混有多种字号时字号框留空（#112）。
- ElyDoc：长 Word 文档排完前几页即可使用，不必等整份文档排完（#111）。
- ElyDoc：句首大写在每个句号后都另起一句。
- ElyDoc：开启修订时，“全部替换”与 `ely-doc text replace` 不再写入已删除的文字（#121）。
- 滚动条不再遮挡内容。
- ElyMark：长表格单元格靠后位置的查找结果会滚入视野（#93）。
- ElyMail：在筛选（如“未读”）下点开的邮件留在列表中，直到切换筛选（#95）；同一地址配两个收件服务器视为两个账户（#96）。
- ElyMail（Windows）：使用 IBM Plex Sans 等字体时字母下半部分（如 g、y）不再被裁切，未读数字在角标中居中。
- Office 文件保存更快：图片直接保存不再重复压缩（#115）；Linux 上大图重绘更快（#116）。
- 启动器（`ely-doc-start` 等）会返回应用的错误码；应用改向系统获取登录用户名；单窗口应用收到 `--new-window` 时照常打开文件。
- ElyTable：边框线型与线宽菜单补全了屏幕阅读器名称。
- 消除依赖安全公告（`cookie` 0.18.3、`url` 2.5.9）。
