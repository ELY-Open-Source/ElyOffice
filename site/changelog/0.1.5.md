# 0.1.5 2026-10-15

## English

### New
- ElyMark works the way Typora does: emoji shortcodes, inline HTML, footnotes, GitHub alert blocks, a `[toc]` outline and front matter; Paragraph and Format menus with Typora's shortcuts; a right-click menu that fits what you clicked; moving table rows and columns; editing a table cell by cell in the visual view.
- ElyDoc: a right-click menu as in Word, with table commands to insert and delete rows, columns and tables, and to merge and split cells; drag a table's borders to resize it. ElyTable and ElyShow have right-click menus too.
- Opening a file while the app is running opens it in the running copy, in a new tab.
- The macOS apps are signed with Developer ID and notarized.

### Fixes
- Submenus no longer jump to the item you pass on the way to them, in every app.
- ElyMark: the recent list can be cleared; single line breaks are kept while you edit; the caret sits right after Chinese characters in source mode; headings step up clearly in size.
- ElyShow: the thumbnail strip scrolls with the wheel; the wheel and arrow keys change slides when a whole slide fits.
- Chinese text on Windows no longer mixes heavy and light glyphs in one word.
- On macOS, ElyDoc, ElyTable and ElyShow show one Dock icon each.
- Upgrading on Windows removes the files the old version left behind.

## 中文

### 新功能
- ElyMark 照 Typora 的方式工作：表情短码、行内 HTML、脚注、GitHub 提示块、`[toc]` 目录、front matter；“段落”“格式”菜单与 Typora 同键；右键菜单随所点之处而变；表格行列可移动；可视视图里按格编辑表格。
- ElyDoc：照 Word 的右键菜单，表格可插入、删除行列与表格，合并、拆分单元格；拖动表格边线调整大小。ElyTable 与 ElyShow 也有右键菜单。
- 应用开着时再打开文件，交给运行中的那份，开成新标签。
- macOS 版以 Developer ID 签名并经公证。

### 修复
- 所有应用：移向子菜单时，路过的菜单项不再抢走子菜单。
- ElyMark：最近列表可以清除；编辑时保留单个换行；源码模式里插入点紧跟在汉字后；各级标题字号分明。
- ElyShow：缩略图条可用滚轮滚动；整页可见时，滚轮与上下键换页。
- Windows 上同一词里的汉字不再粗细不一。
- macOS 上 ElyDoc、ElyTable、ElyShow 在程序坞里各只有一个图标。
- Windows 上升级会移去旧版留下的文件。
