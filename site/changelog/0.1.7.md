# 0.1.7 2026-10-17

## English

- Windows only: right-click a folder or the desktop, then New, to make a blank Word document, Excel workbook, PowerPoint presentation or Markdown file for ElyDoc, ElyTable, ElyShow or ElyMark. If Office, WPS or another app already handles a type, New keeps offering theirs, and Ely leaves it alone.
- macOS and Linux: nothing changed; they stayed on 0.1.6.

## 中文

- 只有 Windows：在文件夹或桌面上右键 › 新建，可建空白的 Word 文档、Excel 工作簿、PowerPoint 演示文稿或 Markdown 文件，由 ElyDoc、ElyTable、ElyShow、ElyMark 打开。某类型已由 Office、WPS 或别的应用处理时，“新建”照旧给它们的，Ely 不去动。
- macOS 与 Linux：没有变化，仍是 0.1.6。
