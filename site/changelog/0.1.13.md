# 0.1.13 2026-10-30

## English

### New
- ElyTable: the AutoFilter value list has a search box. Searching only narrows what you see; values it hides keep their ticks, and All acts on the values shown (#50).
- ElyDoc, ElyShow and ElyMark: like ElyTable, other programs can read and edit an open file from the command line: `ely-doc text`, `ely-show text` and `ely-mark text`, each with `docs`, `get`, `replace` and `save`. A replace is one undo step and leaves your cursor alone. See [Command line](/docs).
- ElyMark: select across paragraphs in the visual view, by dragging or with Shift+Up/Down. Copy, cut, delete, typing and formats such as bold act on the whole selection.
- ElyShow: plays a slide's audio and video on Windows and Linux too.
- ElyMail: can open `mailto:` links on all three systems; it is offered, never made the default by itself. Adding Gmail now says what to do when Google refuses the password.
- ElyTree: Open Terminal and Stop Git on Windows and Linux.
- A document that takes too long to open no longer leaves you at “Opening…”: after 30 seconds a banner offers to stop the document engine (the way out for #49; its cause is still being looked into).
- Update manifests are signed, and an update whose signature doesn't match is refused.

### Fixes
- Windows: a new document saved a second time failed with “The system cannot find the file specified (os error 2)”. Saving a file that was moved or deleted now asks where to save it. Save As adds the extension to a bare name.
- A file named .docx, .xlsx or .pptx that isn't really one fails at once with the reason, instead of importing as plain text for minutes.
- ElyMail: typing on Windows stalled for 0.1–0.2 s now and then.
- Linux: the fcitx5 input method typed nothing under XWayland.
- Dark mode: the New Document dialog's template names were hard to read and its Use button was cut off.
- ElyMark: large files open faster and use less memory; a closed tab no longer keeps its memory.
- Opening and closing documents for a long time no longer builds up memory and handles (on Windows, one handle leaked per lock).
- PPTX sections are never lost silently: a file with sections is saved as a copy, and the original stays as it was.
- ElyTable: functions the engine doesn't know keep the file's results until a cell they use changes.
- The document engine could hang at start on AMD graphics.
- On Windows, the document engine was now and then refused at start.
- ElyTree: when a commit hook refuses, Git's own message is shown.
- In narrow windows, side panels no longer squeeze out the document.
- With the Chinese interface, ElyDoc's built-in style and paper names are in Chinese.
- Screen readers: on Windows (Narrator, NVDA) and Linux (Orca) they read the document's paragraph, caret and selection, and a PDF's page text; on macOS, VoiceOver follows keyboard focus; F6 leaves an ElyMark document.

## 中文

### 新功能
- ElyTable：自动筛选的值列表上方有搜索框。搜索只收窄所见，被搜走的值仍保留原来的勾选，“全选”只作用于所见的值（#50）。
- ElyDoc、ElyShow、ElyMark：与 ElyTable 一样可经命令行读写已打开的文件：`ely-doc text`、`ely-show text`、`ely-mark text`，各有 `docs`、`get`、`replace`、`save`。替换是一步撤销，不动你的光标。见[命令行](/docs#zh)。
- ElyMark：可视视图里可跨段落选取（拖动，或 Shift+上下键），复制、剪切、删除、键入与加粗等格式都作用于整段选区。
- ElyShow：Windows 与 Linux 上也能播放幻灯片里的音频和视频。
- ElyMail：可设为 `mailto:` 链接的打开方式（三端，只供选择，从不自行设为默认）；添加 Gmail 时说明 Google 拒绝密码该怎么办。
- ElyTree：Windows 与 Linux 上也有“打开终端”与“停止 Git”。
- 文档迟迟打不开时，30 秒后出现“停止文档引擎”，不再永远停在“正在打开”（#49 的出路；根因仍在查）。
- 更新清单带签名，签名不符的更新一律拒装。

### 修复
- Windows：新建的文档保存后再保存报“系统找不到指定的文件 (os error 2)”；文件被移走或删掉后按保存，改为询问存到哪里。另存为时只输入名字会自动加上扩展名。
- 名为 .docx、.xlsx、.pptx 而内容并非 Office 文件的，立刻说明原因，不再当作纯文本导入、几分钟打不开。
- ElyMail：Windows 上键入时偶尔卡顿 0.1 至 0.2 秒。
- Linux：XWayland 下 fcitx5 输入法打不了字。
- 深色模式下新建文档对话框的模板名看不清、“使用模板”按钮被截断。
- ElyMark：大文件打开更快、占用内存更少；关掉的标签不再留着内存。
- 长时间开关文档不再越用越多内存和句柄（Windows 上每次加锁漏一个句柄）。
- PPTX 的章节不会悄悄丢失：有章节的文件保存为副本，原文件不动。
- ElyTable：引擎不认识的函数保留文件里原来的结果，直到它引用的单元格改变。
- AMD 显卡上文档引擎启动时可能卡死。
- Windows 上文档引擎偶尔启动即被拒。
- ElyTree：提交钩子拒绝时，显示 Git 的原话。
- 窗口很窄时，面板不再把正文挤没。
- 界面为中文时，ElyDoc 的内置样式名与纸张名显示为中文。
- 读屏软件：Windows（讲述人、NVDA）与 Linux（Orca）读得到文档的段落、插入点与选区，以及 PDF 的页面文字；macOS 的 VoiceOver 跟得上键盘焦点；F6 可离开 ElyMark 的文档。
