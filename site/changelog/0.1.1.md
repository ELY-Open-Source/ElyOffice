# 0.1.1 2026-10-09

## English

- ElyShow: clicking a thumbnail shows that slide at once; the slideshow covers the menu bar and Dock; slides with many layers play on large screens.
- ElyDoc: the page stays centred, and zooming stays on the page.
- ElyTable: clicks and drags land on the cell under them; an AutoFilter on a selection leaves the total below it alone; the status bar's sums follow the cell's number format; a new chart goes beside its data, not on it.
- ElyPDF: the page no longer flashes white after an edit; text in a font subset can be edited.
- ElyTree: one change reads “1 file changed”; diffs are coloured by file type.
- ElyMark: tables written without padding show as tables; task boxes match the text size.
- LibreOffice no longer appears in Open With.

## 中文

- ElyShow：点缩略图即刻显示该页；放映盖住菜单栏与程序坞；图层多的幻灯片在大屏上也能放映。
- ElyDoc：页面保持居中，缩放停在页面上。
- ElyTable：点击与拖选落在指针下的单元格；对选区开自动筛选不再扩到下方的合计行；状态栏的统计按单元格的数字格式显示；新图表放在数据旁，不压住数据。
- ElyPDF：编辑后页面不再闪白；子集字体里的文字也能编辑。
- ElyTree：一处改动写作“1 file changed”；差异按文件类型着色。
- ElyMark：不补齐空格的表格也显示为表格；任务列表的勾选框与文字同大。
- “打开方式”里不再出现 LibreOffice。
