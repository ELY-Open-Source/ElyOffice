# 0.1.2 2026-10-09

## English

### New
- Software updates inside the apps: Check for Updates… in the app menu, or turn on checking at launch in Settings › General (off by default). Updates install after the app quits, and unsaved work is asked about first.
- Each disk image holds an Applications shortcut: drag the app onto it to install.

### Fixes
- Quitting from the Settings window no longer skips the save question.
- ElyDoc, ElyTable and ElyShow start even when the shared settings file cannot be read.
- A second copy of an app no longer wipes the first one's work and recovery data.
- ElyTable: a half-visible cell no longer jumps the sheet; dragging a selection no longer scrolls under the pointer; wide windows show the sheet from the left.
- ElyShow: zooming stays instead of snapping back to the fitted slide.
- ElyDoc: closing a tab with its export or print dialog open no longer crashes; mail merge keeps the template you chose, also after a preview.
- ElyPDF: a folder you may not write to no longer crashes the app; page thumbnails stay through edits; text on a scanned page can be edited, and a shaky click no longer moves the picture; the edit tool opens fast on dense pages.
- ElyMark: typing is no longer lost when another program rewrites the file with the same text, and autosave resumes after such changes.

## 中文

### 新功能
- 应用内更新：应用菜单里的“检查更新…”，或在设置 › 通用里打开启动时检查（默认关）。更新在应用退出后安装，未保存的内容会先问。
- 每个磁盘映像里有“应用程序”替身：把应用拖上去即安装。

### 修复
- 从设置窗口退出不再跳过保存询问。
- 共用的设置文件读不出时，ElyDoc、ElyTable、ElyShow 照样启动。
- 再开一份应用不再清掉第一份的内容与恢复数据。
- ElyTable：露出一半的单元格不再让表格跳动；拖选不再在指针下滚动；宽窗口从左边显示表格。
- ElyShow：缩放后保持，不再弹回适合页面。
- ElyDoc：导出或打印对话框开着时关标签不再崩溃；邮件合并保持你选的模板，预览后也一样。
- ElyPDF：写不进的文件夹不再让应用崩溃；编辑后页面缩略图仍在；扫描页上的文字可编辑，手抖的一下点击不再移动图片；文字密集的页面上编辑工具打开很快。
- ElyMark：别的程序以相同文字改写文件时，键入不再丢失，自动保存随后照常。
