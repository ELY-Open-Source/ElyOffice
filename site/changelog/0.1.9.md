# 0.1.9 2026-10-20

## English

### Fixes
- Paste failed on Windows. Plain text copied from Notepad, a browser and similar would not paste into ElyDoc, ElyTable or ElyShow; the only message was “the clipboard reads”. Fixed. A failed paste now shows the whole cause.
- ElyTable: turning on AutoFilter for a whole column with no clear header crashed the engine (#4). The first row is now the header, as in Excel.
- ElyShow: with more masters than slides, Edit Master kept reporting “no visibility” (#2).
- Selected text stays readable in every theme. Opaque selection colours, as in Omarchy, used to cover the selected text (PR #1, thanks @OmarGonD).
- ElyTable: Enter accepts the highlighted function (it used to commit half a formula and move down). Clicking a candidate, a dropdown arrow or an input note no longer reaches the cell beneath (PR #6, thanks @FMVPJet).
- The Word formula fix from 0.1.8 had reached only the Windows build. macOS and Linux have it now.

### Other
- Code and releases moved to GitHub.
- Ely Office's own code is now MIT licensed, and earlier versions are licensed under MIT as well. Bundled engines keep their own licences.
- Updating: 0.1.8 and earlier looked for updates on the old Gitea server, where this release was published too. From 0.1.9 on, updates come from GitHub.

## 中文

### 修复
- Windows 上粘贴不可用。从记事本、浏览器等复制的纯文字粘不进 ElyDoc、ElyTable、ElyShow，只提示“the clipboard reads”。现已修好；粘贴失败时提示写出完整原因。
- ElyTable：选中整列开自动筛选，若该列看不出标题，引擎崩溃（#4）。现在首行作标题，同 Excel。
- ElyShow：母版比幻灯片多时，“编辑母版”反复报 “no visibility”（#2）。
- 选中的文字在任何主题下都看得清。Omarchy 等主题的选区色不透明，原先盖住所选文字（PR #1，感谢 @OmarGonD）。
- ElyTable：函数候选可用 Enter 接受（原先 Enter 提交半个公式并下移）；点候选、下拉箭头或输入说明不再点到其下的单元格（PR #6，感谢 @FMVPJet）。
- 0.1.8 里 Word 公式的修复原先只进了 Windows 版，现在 macOS 与 Linux 也有。

### 其他
- 代码与发布搬到 GitHub。
- Ely Office 自己的代码改为 MIT 许可，此前的版本同样以 MIT 授权。随带的引擎照其原许可。
- 更新：0.1.8 及更早的版本在旧的 Gitea 上查更新，本版也发在那里。0.1.9 起改从 GitHub 查更新。
