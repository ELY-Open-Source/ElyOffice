Ely Office

Command line

ElyTable from 0.1.12; ElyDoc and ElyShow from 0.1.13

Scripts and AI agents can read and edit a document while it is open in ElyDoc, ElyTable or ElyShow, then save it. Each command asks the copy of the app that is already running, so the app must be open with that file. A request comes only from your own account on the same computer; nothing listens on the network.

Edits go into the open document as if you had made them, and you can undo them. Your cursor and selection stay where they were.

Where the command is

The command is the app itself, given arguments:

  • macOS: /Applications/ElyDoc.app/Contents/MacOS/ely-doc, and likewise ElyTable.app/…/ely-table and ElyShow.app/…/ely-show.
  • Windows: %LOCALAPPDATA%\Programs\Ely Office\ElyDoc\ely-doc.exe, and likewise for ElyTable and ElyShow, unless you chose another folder when installing.
  • Linux (deb, rpm, Arch): ely-doc, ely-table and ely-show are on your PATH.
  • Linux (AppImage): run the AppImage with the same arguments.

ElyDoc

ely-doc text docs
ely-doc text get FILE
ely-doc text replace FILE FIND WITH
ely-doc text save FILE
  • docs lists the files open in ElyDoc, one full path per line.
  • get prints the body text, one paragraph per line. Footnotes, comments, text frames and deleted tracked changes are left out.
  • replace changes every exact, case-matched FIND in the body to WITH, as one undo step. Both must stay within one paragraph. If FIND is nowhere in the body, nothing changes and the command fails.
  • save saves the file and prints its path once the save is on disk.
$ ely-doc text get report.docx
Quarterly report
Sales rose in March.
$ ely-doc text replace report.docx March April
$ ely-doc text save report.docx
/home/me/report.docx

ElyTable

ely-table cell docs
ely-table cell get FILE ADDRESS
ely-table cell set FILE ADDRESS TEXT
ely-table cell save FILE
  • ADDRESS always names its sheet, as in Sheet1!A1. An address without a sheet is refused.
  • get prints the cell as one line of JSON: its full address, the text shown in the cell, and what was typed into it.
  • set types TEXT into the cell, as one undo step. Text starting with = is a formula in Excel's A1 style, and numbers are written as in English (3.5).
  • docs and save work as in ElyDoc.
$ ely-table cell set budget.xlsx 'Sheet1!B2' '=6*7'
$ ely-table cell get budget.xlsx 'Sheet1!B2'
{"address":"Sheet1!$B$2","text":"42","input":"=6*7"}
$ ely-table cell save budget.xlsx
/home/me/budget.xlsx

ElyShow

ely-show text docs
ely-show text get FILE
ely-show text replace FILE FIND WITH
ely-show text save FILE
  • get prints the text on each slide, one paragraph per line, with a form feed between slides. Speaker notes and comments are left out.
  • replace changes every exact, case-matched FIND on the slides. As in Impress, each text box it changes is one undo step. The current slide and the selection stay as they were.
  • docs and save work as in ElyDoc.
$ ely-show text replace pitch.pptx 2025 2026
$ ely-show text save pitch.pptx
/home/me/pitch.pptx

Files and answers

  • FILE may be relative to the current folder. It must be a file open in the app; a new document gets a name only once it is saved.
  • Some files are kept as they were and saved only as a copy, such as a presentation with sections. For those, and for a file deleted from disk, save fails and says so; save them in the app.
  • Exit codes: 0 done; 1 refused, such as the app not running or the file not open, with the reason on standard error; 2 the command was not understood, with usage.

Windows: PowerShell and cmd

The apps are windowed programs, and PowerShell does not wait for one unless its output goes through a pipe. Without a pipe you get no answer and no exit code. In PowerShell, pipe the command: 

$doc = "$env:LOCALAPPDATA\Programs\Ely Office\ElyDoc\ely-doc.exe"
$text = & $doc text get report.docx | Out-String
$LASTEXITCODE

Start-Process -Wait -NoNewWindow -PassThru also waits and gives the exit code. Batch files, cmd /c and Git Bash wait as usual.

ElyMark has the same commands for Markdown, as ely-mark text.

命令行

ElyTable 自 0.1.12 起；ElyDoc 与 ElyShow 自 0.1.13 起

脚本与 AI 代理可以读写在 ElyDoc、ElyTable、ElyShow 里打开着的文档，并保存。每条命令问的是已在运行的那份应用，所以应用必须开着、并打开了这个文件。请求只来自本机你自己的账户，不在网络上监听。

改动像你亲手改的一样进入打开着的文档，可以撤销；你的光标与选区不动。

命令在哪里

命令就是应用本身，带上参数：

  • macOS：/Applications/ElyDoc.app/Contents/MacOS/ely-doc，ElyTable、ElyShow 同理（ElyTable.app/…/ely-table、ElyShow.app/…/ely-show）。
  • Windows：%LOCALAPPDATA%\Programs\Ely Office\ElyDoc\ely-doc.exe，ElyTable、ElyShow 同理；安装时选了别的文件夹则在那里。
  • Linux（deb、rpm、Arch）：ely-doc、ely-table、ely-show 已在 PATH 上。
  • Linux（AppImage）：用同样的参数运行 AppImage。

ElyDoc

ely-doc text docs
ely-doc text get FILE
ely-doc text replace FILE FIND WITH
ely-doc text save FILE
  • docs 列出 ElyDoc 里打开的文件，一行一个完整路径。
  • get 输出正文，一段一行，不含脚注、批注、文本框与已删除的修订。
  • replace 把正文里每一处与 FIND 完全相同（区分大小写）的文字换成 WITH，一步撤销。两者都不能跨段。正文里一处 FIND 也没有时什么都不改，命令失败。
  • save 保存文件，写到磁盘后输出其路径。
$ ely-doc text get report.docx
季度报告
三月销量上升。
$ ely-doc text replace report.docx 三月 四月
$ ely-doc text save report.docx
/home/me/report.docx

ElyTable

ely-table cell docs
ely-table cell get FILE ADDRESS
ely-table cell set FILE ADDRESS TEXT
ely-table cell save FILE
  • ADDRESS 一律写明工作表，如 Sheet1!A1；不带工作表的地址被拒。
  • get 以一行 JSON 输出该格：完整地址、格里显示的文字、键入的内容。
  • set 把 TEXT 键入该格，一步撤销。以 = 开头的是公式，照 Excel 的 A1 写法；数字照英文写法（3.5）。
  • docs 与 save 同 ElyDoc。
$ ely-table cell set budget.xlsx 'Sheet1!B2' '=6*7'
$ ely-table cell get budget.xlsx 'Sheet1!B2'
{"address":"Sheet1!$B$2","text":"42","input":"=6*7"}
$ ely-table cell save budget.xlsx
/home/me/budget.xlsx

ElyShow

ely-show text docs
ely-show text get FILE
ely-show text replace FILE FIND WITH
ely-show text save FILE
  • get 输出每张幻灯片上的文字，一段一行，幻灯片之间是换页符；不含演讲者备注与批注。
  • replace 替换幻灯片上每一处与 FIND 完全相同（区分大小写）的文字。与 Impress 一样，每个改到的文本框是一步撤销。当前幻灯片与选中照旧。
  • docs 与 save 同 ElyDoc。
$ ely-show text replace pitch.pptx 2025 2026
$ ely-show text save pitch.pptx
/home/me/pitch.pptx

文件与答复

  • FILE 可以相对于当前文件夹，但必须是应用里打开着的文件；新建的文档保存后才有名字。
  • 有些文件保持原样、只能另存副本，如带章节的演示文稿。这类文件以及已从磁盘删除的文件，save 会失败并说明原因，请在应用里保存。
  • 退出码：0 完成；1 被拒，如应用没在运行、文件没打开，原因写在标准错误；2 命令看不懂，并给出用法。

Windows：PowerShell 与 cmd

这些应用是窗口程序，PowerShell 只有在输出经管道时才会等它，否则拿不到答复，也没有退出码。在 PowerShell 里请接上管道：

$doc = "$env:LOCALAPPDATA\Programs\Ely Office\ElyDoc\ely-doc.exe"
$text = & $doc text get report.docx | Out-String
$LASTEXITCODE

Start-Process -Wait -NoNewWindow -PassThru 也会等待并给出退出码。批处理文件、cmd /c 与 Git Bash 照常等待。

ElyMark 对 Markdown 有同样的命令：ely-mark text。
