Ely Office

Command line

ElyTable from 0.1.12; ElyDoc and ElyShow from 0.1.13; the other commands from 0.1.18

Scripts and AI agents can open, create, read, edit, export and save documents in ElyDoc, ElyTable, ElyShow and ElyMark. open and new start the app if needed; the rest ask the copy already running with that file open. A request comes only from your own account on the same computer; nothing listens on the network.

Edits go into the open document as if you had made them, and you can undo them. Your cursor, selection and current slide stay where they were.

Where the command is

The command is the app itself, given arguments:

  • macOS: /Applications/ElyDoc.app/Contents/MacOS/ely-doc, and likewise ElyTable.app/…/ely-table, ElyShow.app/…/ely-show and ElyMark.app/…/ely-mark.
  • Windows: %LOCALAPPDATA%\Programs\Ely Office\ElyDoc\ely-doc.exe, and likewise for ElyTable, ElyShow and ElyMark, unless you chose another folder when installing.
  • Linux (deb, rpm, Arch): ely-doc, ely-table, ely-show and ely-mark are on your PATH.
  • Linux (AppImage): run the AppImage with the same arguments.

Common commands

  • docs lists the saved files open in the app as a JSON array of full paths.
  • open FILE opens FILE, starting the app first if needed, and prints its path as a JSON string once loaded.
  • new FILE creates a blank file for its extension (the same on all three platforms), opens it and prints its path as a JSON string; refused if the file already exists.
  • export FILE TARGET writes a copy in the format of TARGET's extension (such as .pdf) and prints the target path as a JSON string, leaving the open document untouched.
  • save FILE saves the file and prints its path as a JSON string once on disk. Older forms such as cell docs and text save still work.

ElyDoc

ely-doc docs
ely-doc open FILE
ely-doc new FILE
ely-doc export FILE TARGET
ely-doc save FILE
ely-doc text get FILE [--json]
ely-doc text replace FILE FIND WITH
ely-doc text append FILE TEXT [--style STYLE]
ely-doc format FILE FIND PROPERTY=VALUE ...
ely-doc table insert FILE DATA [--after FIND] [--header]
ely-doc image insert FILE IMAGE [--after FIND] [--width SIZE]
  • text get prints the body text, one paragraph per line; --json prints a JSON array of {"style", "text"} objects. Footnotes, comments, text frames and deleted tracked changes are left out.
  • text replace changes every exact, case-matched FIND (non-empty, within one paragraph) to WITH; newlines in WITH start new paragraphs in the same style. Fails when there is no match.
  • text append adds lines as paragraphs at the end; --style takes an English paragraph style name (such as Heading 1).
  • format styles every exact, case-matched FIND: bold, italic, underline (on|off), font, size (1–999 pt), color (#RRGGBB|none) and style (English paragraph style for each matching paragraph).
  • table insert adds a JSON 2-D string array or TSV (equal-length rows, up to 1,000,000 cells) at the end or after the first matching paragraph (--after FIND); --header repeats row 1 across pages.
  • image insert embeds IMAGE (PNG, JPEG, GIF, SVG, BMP, TIFF, WebP and more) in its own paragraph at the end or --after FIND, shrunk to fit the text width; --width SIZE sets the width (cm, mm, in or pt, 1pt–100cm, ratio kept).
  • Each write is one undo step and keeps your cursor and selection.
$ ely-doc text replace report.docx March April
$ ely-doc format report.docx "Chapter 1" bold=on style="Heading 1"
$ ely-doc save report.docx
"/home/me/report.docx"

ElyTable

ely-table docs | open FILE | new FILE | export FILE TARGET | save FILE
ely-table cell get FILE ADDRESS | cell set FILE ADDRESS TEXT
ely-table range get FILE ADDRESS | range set FILE ADDRESS DATA
ely-table range merge|unmerge FILE ADDRESS
ely-table format FILE ADDRESS PROPERTY=VALUE ...
ely-table sheet list FILE
ely-table sheet add FILE NAME [POSITION]
ely-table sheet remove FILE SHEET
ely-table sheet rename FILE SHEET NAME
ely-table sheet freeze FILE ADDRESS
ely-table rows insert|delete FILE ADDRESS
ely-table rows height FILE ADDRESS SIZE
ely-table columns insert|delete FILE ADDRESS
ely-table columns width FILE ADDRESS SIZE
  • ADDRESS always names its sheet, as in Sheet1!A1, Sheet1!A1:C3, Sheet1!5:7 or Sheet1!C:E.
  • cell get prints JSON (address, text, input); cell set writes TEXT (= starts an Excel A1 formula; numbers use English format such as 3.5).
  • range get prints JSON (address, rows; a bare sheet name such as Sheet1 reads its used area, up to 1,000,000 cells). range set writes a JSON 2-D string array or TSV ("" clears a cell, = for formulas).
  • range merge merges the cells, keeping hidden values so range unmerge restores them; overlapping merges must be unmerged first.
  • format sets bold, italic, underline, wrap (on|off), font, size (1–999), color/background (#RRGGBB|none), number (en-US, e.g. 0.00, 0%), align (left|center|right|justify|general), valign (top|middle|bottom|standard), border (all|outer|none) and border-left|top|right|bottom|inner-h|inner-v (none or style:width:#RRGGBB, width in pt/mm up to 2mm).
  • sheet, rows and columns manage sheets (list prints JSON; POSITION starts at 1; freeze locks above and left of ADDRESS, A1 unfreezes), insert or delete rows and columns, and set row height or column width (SIZE in cm, mm, in, pt or auto).
  • Each write is one undo step and keeps your cursor, selection and current sheet (deleting the shown sheet moves to a neighbour).
$ ely-table range set budget.xlsx 'Sheet1!A1' '[["Item","Total"],["Rent","=600*2"]]'
$ ely-table format budget.xlsx 'Sheet1!A1:B1' bold=on background=#FFF2CC
$ ely-table range get budget.xlsx Sheet1

ElyShow

ely-show docs
ely-show open FILE
ely-show new FILE
ely-show export FILE TARGET
ely-show save FILE
ely-show text get FILE
ely-show text replace FILE FIND WITH
ely-show text set FILE N title|body TEXT
ely-show notes get FILE N
ely-show notes set FILE N TEXT
ely-show slide list FILE
ely-show slide add FILE [POSITION] [--layout NAME]
ely-show slide duplicate FILE N
ely-show slide delete FILE N
ely-show slide move FILE N TO
ely-show image insert FILE N IMAGE [--width SIZE]
  • text get prints each slide's text, one paragraph per line, with a form feed between slides (speaker notes and comments are left out).
  • text replace changes every exact, case-matched FIND across all slides; newlines in WITH start new paragraphs, and each text box changed is one undo step.
  • text set and notes get|set work on slide N (from 1), one line per paragraph (empty TEXT clears). Refused if the slide has no such placeholder or if existing text has mixed formatting.
  • slide list prints JSON (number, name, layout, title, hidden); add inserts at POSITION (default last) with --layout (default title-content; 12 layouts listed by ely-show --help); duplicate, delete (refused on the only slide) and move restructure the deck.
  • image insert centers IMAGE on slide N, shrunk to fit the slide (ratio kept); --width SIZE accepts cm, mm, in or pt (1pt–100cm).
  • Each write (other than text replace) is one undo step; the shown slide and selection stay unchanged (deleting the shown slide shows a neighbour).
$ ely-show slide add pitch.pptx --layout title-content
$ ely-show text set pitch.pptx 2 title "Q4 Review"
$ ely-show image insert pitch.pptx 2 chart.png --width 12cm

ElyMark

ely-mark docs
ely-mark open FILE
ely-mark new FILE
ely-mark export FILE TARGET
ely-mark save FILE
ely-mark text get FILE
ely-mark text replace FILE FIND WITH
ely-mark text set FILE TEXT
ely-mark text append FILE TEXT
  • FILE must be open in ElyMark for text commands; text get works in preview mode too, while replace, set and append are refused.
  • get prints the Markdown as it stands, byte for byte, unsaved typing included.
  • replace changes every exact, case-matched FIND in the Markdown; fails when there is no match.
  • set replaces the whole Markdown (empty TEXT clears the file); append adds non-empty TEXT on a new line at the end (start with a blank line for a new paragraph). Both keep the file's line endings (LF or CRLF).
  • Each edit is one undo step; typing in another block is not interrupted.
$ ely-mark text set notes.md - < draft.md
$ ely-mark text append notes.md "Next step"
$ ely-mark save notes.md
"/home/me/notes.md"

Files and answers

  • FILE may be relative to the current folder. Other than open and new, it must be a file already open in the app; a new document gets a name only once it is saved.
  • Any argument written as - is read from standard input (UTF-8, up to 64 MiB). Structured results are printed as JSON; errors go to standard error.
  • Some files are kept as they were and saved only as a copy, such as a presentation with sections. For those, and for a file deleted from disk, save fails and says so; in ElyDoc, ElyTable and ElyShow, a file changed on disk is not overwritten and the app asks you instead.
  • Exit codes: 0 done; 1 refused or failed, with the reason on standard error; 2 wrong usage, with usage; 3 the app is not running.

Windows: PowerShell and cmd

The apps are windowed programs, and PowerShell does not wait for one unless its output goes through a pipe. Without a pipe you get no answer and no exit code. In PowerShell, pipe the command:

$doc = "$env:LOCALAPPDATA\Programs\Ely Office\ElyDoc\ely-doc.exe"
$text = & $doc text get report.docx | Out-String
$LASTEXITCODE

Start-Process -Wait -NoNewWindow -PassThru also waits and gives the exit code. Batch files, cmd /c and Git Bash wait as usual.

ElyPDF has no command line on purpose: PDFs are read and annotated in ElyPDF, and scripts can work directly with exported PDFs.

命令行

ElyTable 自 0.1.12 起；ElyDoc 与 ElyShow 自 0.1.13 起；其余命令自 0.1.18 起

脚本与 AI 代理可以经命令行在 ElyDoc、ElyTable、ElyShow、ElyMark 里打开、新建、读写、导出并保存文档。open 与 new 会在应用未开时先启动；其余命令问的是已在运行的那份应用，文件须处于打开状态。请求只来自本机你自己的账户，不在网络上监听。

改动像你亲手改的一样进入打开着的文档，可以撤销；你的光标、选区与当前幻灯片不动。

命令在哪里

命令就是应用本身，带上参数：

  • macOS：/Applications/ElyDoc.app/Contents/MacOS/ely-doc，ElyTable、ElyShow、ElyMark 同理（ElyTable.app/…/ely-table、ElyShow.app/…/ely-show、ElyMark.app/…/ely-mark）。
  • Windows：%LOCALAPPDATA%\Programs\Ely Office\ElyDoc\ely-doc.exe，ElyTable、ElyShow、ElyMark 同理；安装时选了别的文件夹则在那里。
  • Linux（deb、rpm、Arch）：ely-doc、ely-table、ely-show、ely-mark 已在 PATH 上。
  • Linux（AppImage）：用同样的参数运行 AppImage。

共通命令

  • docs 以完整路径的 JSON 数组列出应用里打开的已存文件。
  • open FILE 打开文件；应用未开时先启动，等载入完以 JSON 字符串输出路径。
  • new FILE 按扩展名建一份空白文件（三端相同）、打开并以 JSON 字符串输出路径；文件已存在即拒绝。
  • export FILE TARGET 按目标扩展名（如 .pdf）导出副本并以 JSON 字符串输出目标路径；原文档与会话不动。
  • save FILE 保存文件，写到磁盘后以 JSON 字符串输出路径；旧写法（如 cell docs、text save）照常可用。

ElyDoc

ely-doc docs
ely-doc open FILE
ely-doc new FILE
ely-doc export FILE TARGET
ely-doc save FILE
ely-doc text get FILE [--json]
ely-doc text replace FILE FIND WITH
ely-doc text append FILE TEXT [--style STYLE]
ely-doc format FILE FIND PROPERTY=VALUE ...
ely-doc table insert FILE DATA [--after FIND] [--header]
ely-doc image insert FILE IMAGE [--after FIND] [--width SIZE]
  • text get 输出正文，一段一行；加 --json 输出每段含 style 与 text 的 JSON 数组。脚注、批注、文本框与已删除的修订不在其中。
  • text replace 把正文里每处 FIND（不为空、区分大小写、不跨段）换成 WITH；WITH 可带换行，每处换行起新段并沿用原段样式；一处也没有即报错。
  • text append 在正文末尾追加段落，一行一段；--style 用英文样式名（如 Heading 1）。
  • format 把每处匹配设为指定格式：bold、italic、underline（on|off）、font、size（1–999 磅）、color（#RRGGBB|none）与 style（所在段英文段落样式）。
  • table insert 在文末或首处匹配段后（--after FIND）插入二维 JSON 字符串数组或 TSV 表格（每行等长，上限 100 万格）；--header 设首行为跨页标题行。
  • image insert 在文末或 --after FIND 后以独立新段嵌入图片（PNG、JPEG、GIF、SVG、BMP、TIFF、WebP 等），超宽自动缩入版心；--width SIZE 支持 cm、mm、in、pt（1pt–100cm，等比）。
  • 每次修改是一步撤销，不动光标与选区。
$ ely-doc text replace report.docx 三月 四月
$ ely-doc format report.docx "第一章" bold=on style="Heading 1"
$ ely-doc save report.docx
"/home/me/report.docx"

ElyTable

ely-table docs | open FILE | new FILE | export FILE TARGET | save FILE
ely-table cell get FILE ADDRESS | cell set FILE ADDRESS TEXT
ely-table range get FILE ADDRESS | range set FILE ADDRESS DATA
ely-table range merge|unmerge FILE ADDRESS
ely-table format FILE ADDRESS PROPERTY=VALUE ...
ely-table sheet list FILE
ely-table sheet add FILE NAME [POSITION]
ely-table sheet remove FILE SHEET
ely-table sheet rename FILE SHEET NAME
ely-table sheet freeze FILE ADDRESS
ely-table rows insert|delete FILE ADDRESS
ely-table rows height FILE ADDRESS SIZE
ely-table columns insert|delete FILE ADDRESS
ely-table columns width FILE ADDRESS SIZE
  • ADDRESS 一律写明工作表，如 Sheet1!A1、Sheet1!A1:C3、Sheet1!5:7、Sheet1!C:E。
  • cell get 输出 JSON（address、text、input）；cell set 写入 TEXT（= 开头为 Excel A1 公式，数字照英文写法如 3.5）。
  • range get 输出 JSON（address、rows；只写工作表名如 Sheet1 取已用区域，最多 100 万格）。range set 写入二维 JSON 字符串数组或 TSV（"" 清空，= 开头为公式）。
  • range merge 合并区域，隐藏格内容保留以便 range unmerge 恢复；与已有合并块重叠时须先取消合并。
  • format 可设 bold、italic、underline、wrap（on|off）、font、size（1–999）、color/background（#RRGGBB|none）、number（en-US，如 0.00、0%）、align（left|center|right|justify|general）、valign（top|middle|bottom|standard）、border（all|outer|none）与 border-left|top|right|bottom|inner-h|inner-v（none 或 线型:宽:#RRGGBB，宽用 pt/mm，上限 2mm）。
  • sheet、rows、columns 管理工作表（list 输出 JSON；POSITION 从 1 起；freeze 冻结该格上方与左侧，A1 取消）、增删行列并设行高列宽（SIZE 用 cm、mm、in、pt 或 auto）。
  • 每次修改是一步撤销，不动光标、选区与当前表（删掉当前表时改显相邻表）。
$ ely-table range set budget.xlsx 'Sheet1!A1' '[["项目","合计"],["房租","=600*2"]]'
$ ely-table format budget.xlsx 'Sheet1!A1:B1' bold=on background=#FFF2CC
$ ely-table range get budget.xlsx Sheet1

ElyShow

ely-show docs
ely-show open FILE
ely-show new FILE
ely-show export FILE TARGET
ely-show save FILE
ely-show text get FILE
ely-show text replace FILE FIND WITH
ely-show text set FILE N title|body TEXT
ely-show notes get FILE N
ely-show notes set FILE N TEXT
ely-show slide list FILE
ely-show slide add FILE [POSITION] [--layout NAME]
ely-show slide duplicate FILE N
ely-show slide delete FILE N
ely-show slide move FILE N TO
ely-show image insert FILE N IMAGE [--width SIZE]
  • text get 输出每张幻灯片的文字，一段一行，页间为换页符；不含备注与批注。
  • text replace 遍及全部幻灯片替换每处 FIND（区分大小写、不跨段）；WITH 中的换行起新段，每个改到的文本框是一步撤销。
  • text set 与 notes get|set 按页号 N（从 1 起）读写占位符或备注，一行一段（空 TEXT 即清空）；无此占位符或原有文字含多种格式时拒绝。
  • slide list 输出 JSON（number、name、layout、title、hidden）；add 在 POSITION 新建一页（默认末页，--layout 默认 title-content，12 种版式见 ely-show --help）；duplicate、delete（仅剩一页时拒绝）与 move 调整页序。
  • image insert 在第 N 页居中嵌入 IMAGE，超出时等比缩入页内；--width SIZE 支持 cm、mm、in、pt（1pt–100cm）。
  • 除 text replace 外均为一步撤销，不切换当前页、不动选中对象（删掉当前页时改显相邻页）。
$ ely-show slide add pitch.pptx --layout title-content
$ ely-show text set pitch.pptx 2 title "季度复盘"
$ ely-show image insert pitch.pptx 2 chart.png --width 12cm

ElyMark

ely-mark docs
ely-mark open FILE
ely-mark new FILE
ely-mark export FILE TARGET
ely-mark save FILE
ely-mark text get FILE
ely-mark text replace FILE FIND WITH
ely-mark text set FILE TEXT
ely-mark text append FILE TEXT
  • 执行 text 命令时，FILE 须在 ElyMark 中打开；预览模式下 text get 仍可用，replace、set、append 会被拒绝。
  • get 输出此刻的 Markdown 原文，一字不差，含尚未写回的键入。
  • replace 把每处 FIND（区分大小写）换成 WITH；一处也没有即报错。
  • set 换掉整篇 Markdown（空 TEXT 即清空）；append 在文末另起一行追加非空 TEXT（另起一段请以空行开头）。两者均沿用文件原有换行符（LF 或 CRLF）。
  • 每次修改是一步撤销；你在别处打字时不打断。
$ ely-mark text set notes.md - < draft.md
$ ely-mark text append notes.md "下一步"
$ ely-mark save notes.md
"/home/me/notes.md"

文件与答复

  • FILE 可以相对于当前文件夹。除 open 与 new 外，必须是应用里已打开的文件；新建文档保存后才有名字。
  • 任一参数写成 - 即从标准输入读入文本（UTF-8，上限 64 MiB）。结构化结果输出为 JSON，错误写到标准错误。
  • 有些文件保持原样、只能另存副本，如带章节的演示文稿。这类文件以及已从磁盘删除的文件，save 会失败并说明原因；ElyDoc、ElyTable、ElyShow 遇到文件在磁盘上被改过时不覆盖，在应用里询问。
  • 退出码：0 完成；1 被拒或失败，原因写在标准错误；2 用法不对，并给出用法；3 应用未运行。

Windows：PowerShell 与 cmd

这些应用是窗口程序，PowerShell 只有在输出经管道时才会等它，否则拿不到答复，也没有退出码。在 PowerShell 里请接上管道：

$doc = "$env:LOCALAPPDATA\Programs\Ely Office\ElyDoc\ely-doc.exe"
$text = & $doc text get report.docx | Out-String
$LASTEXITCODE

Start-Process -Wait -NoNewWindow -PassThru 也会等待并给出退出码。批处理文件、cmd /c 与 Git Bash 照常等待。

ElyPDF 刻意不提供命令行：PDF 在 ElyPDF 里阅读与批注，脚本可直接处理导出的 PDF。
