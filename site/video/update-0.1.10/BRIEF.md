## Intent

The 0.1.9 → 0.1.10 update film. ElyMail is the headline. Everything else in the release follows as a fast, playful montage. The tone is light and fun, and every frame should look like a motion and UI/UX designer's showreel.
The user asked for: Liquid Motion (sticky, stringy, merging, bouncing, glossy enough to pinch), aurora gradients and glassmorphism, bilingual (Chinese + English) subtitles, music, and a final video exported directly. There is no screen recording; every UI is drawn.

## Assets

- ../../../assets/icons/ely-*.svg: the official app icons (shapeless masters), used where blobs settle into icons.
- ../update-0.1.5/public/fonts: Noto Sans SC, Inter, JetBrains Mono (local, embeddable).
- Release notes: GitHub release v0.1.10 body (Chinese + English); facts in agents.md decisions C12.x, R10.x.

## Customizations

- Custom WebGL liquid engine: glossy metaballs with smooth-min merging, capsule strings, squash and stretch, refraction, chromatic edges and liquid typography from blurred text fields.
- An original synthesized score (120 BPM, 45 bars = 90 s) plus a synthesized SFX set (bloop, drip, stretch, pop, clink, whoosh, ding).
- A bilingual caption track in a gooey glass pill.

## Notes

- The real versions are 0.1.9 → 0.1.10 (the user wrote 1.0.9 → 1.0.10).
- No provider logos; Gmail, Microsoft, iCloud, IMAP and POP3 appear as text chips.
- Only claim what the release notes and agents.md say shipped. The search stat is measured: 100k messages, median 0.15 s (C12.16, Windows).
