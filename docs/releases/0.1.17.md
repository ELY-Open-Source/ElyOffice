# 0.1.17

Moved from the release notes on 2026-11-20: the user wants the notes to hold only New and Fixes.

- Released 6 days after 0.1.16: fixes the user reported were ready: Chinese fonts drawn in brush faces, slideshow keys that did nothing, dragging objects in ElyShow, and an extra shape drawn after inserting one.
- 1 fix was made after its last review failed and has not been reviewed again (R15.11g); its review needs a Windows machine with Microsoft Office. R15.11 and R15.11c, counted here before, passed review round 4 under R19.3 (a3eab32d, 2026-11-20).
- 33 tasks used up their review rounds or wait on something outside the project; each is marked `[!]` in `tasks/TASKS.md` with what is left.
- Dragging objects in ElyShow needs kernel patch 0140; it is tested on Linux and macOS, not yet by hand on Windows. The slideshow keys were fixed for the case reproduced here; the conditions of the user's report were not reproduced.
- Kernel patches 0132 to 0146, MuPDF patches 0009 to 0011, gpui-pre 0.3.12 with patches 0014 to 0015.
- No arm64 builds for Linux or Windows.
- macOS idle gate: the release Mac (7885) runs another session's Godot game, launched and quit every 1 to 7 minutes. Each launch or quit makes WindowServer wake every AppKit process, the idle engines among them: fonts' window of 07:12 to 07:22 UTC on 2026-11-21 read 28880, 30079 and 28667 mach units, and every wake traced matched a Godot assertion in `pmset -g log` within a second (07:41:29, 07:42:10, 07:47:34, 07:54:57, 07:57:39), with 0 between them; a windowless AppKit program with no Ely code woke at the same seconds. The gate stays at 0: from R20.107 a macOS window in which another process makes or releases a PreventUserIdle assertion is void and rerun, and three void windows fail. The root fix, an engine with no WindowServer connection, is R20.108, after 0.1.17.
- macOS gate passed (fonts, 2026-11-21): `scripts/release-tests.sh` on 4b3cc4d8, from a fresh copy on the release Mac under its test lock with no desktop input, exited 0 at 11:06:39 UTC: `cargo test --workspace` 3979 passed, 0 failed, 8 ignored, engines required; `tests/scripts/vendor-tests.sh` passed; the idle check's window 1 was void, coreaudiod (pid 750) releasing PreventUserIdle assertions at 10:47:38 UTC, and window 2 was judged at 0, 0 and 0 mach units in 600 s for the ElyDoc, ElyTable and ElyShow engines (31, 31 and 27 MB). `scripts/mac-ready.sh ely-notary` passed at 11:06:40: coreaudiod answers and notarytool reads the profile. - Main is sound after the landing-script audit (2026-11-21): on a fresh clone of d33c7cd2 the 18 checks of pr.yml's checks job, run one by one with their own exits, all pass, so the landings whose checks were joined by `&&` let nothing broken land; pr.yml run 44849823981 on d33c7cd2 passed in full.
