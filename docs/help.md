# 帮助

## 打开与保存

- 文件菜单在每个应用里相同：新建、打开、保存（Cmd+S）、另存为、导出（Cmd+E）、打印（Cmd+P）；Cmd+W 关闭标签，Cmd+, 打开设置。
- 新建的文档在第一次保存时才选位置。保存保留原格式；另存为写新文件，原文件不动。
- 含宏的文件、已签名的 PDF、修复过的 PDF 只能另存副本，上方提示条写明原因。
- 外部程序改了你正在编辑的文件时，Ely 不覆盖，询问从磁盘重载、保留你的版本或另存副本（ElyMark 另可逐处比较合并）。
- 打印走系统的打印对话框。设置“文档”里的“双面打印”预设对话框的初始状态（随打印机、单面、长边翻转或短边翻转），对话框里仍可改。
- 自动保存：ElyMark 对有路径的文件停手 1 秒后保存。ElyDoc、ElyTable、ElyShow、ElyPDF 默认手动保存，可在设置“文档”里打开“自动保存”：只对本应用自有格式、无宏无签名的文件，外部改动或保存失败后停下等你处理。

## 缩放、侧栏与窗口宽度

- ElyDoc、ElyTable、ElyShow：Cmd+= 放大，Cmd+- 缩小，Cmd+0 回到实际大小（ElyShow 为适合幻灯片）；也可在“视图”菜单、状态栏右侧的缩放控件，或按住 Cmd 滚动、触控板捏合（以指针处为中心）。范围 25% 至 400%。
- ElyPDF：同样的键、“视图”菜单与状态栏右侧的缩放控件；缩放后停在原来读到的位置。
- 设置“文档”里的“默认缩放”定此后打开的文档的缩放：自动（ElyShow 适合幻灯片，ElyPDF 适合页宽，其余 100%）或 50% 至 200%。已打开的文档不变。
- 侧栏可收起：Cmd+Alt+S 收起或展开左栏，Cmd+Alt+B 右栏，“视图”菜单里也有“左侧栏”“右侧栏”。按应用记住，重开照旧。ElyMail 与 ElyTree 没有“视图”菜单，用键。
- 设置“通用”里可选界面字体与界面字号（12 至 16），所有应用即时随之改变。
- 窗口变窄时，两侧栏先变窄，再先收起右栏、后收起左栏，文档区至少保留 360 点；窗口变宽即回来。侧栏的宽度可拖动内侧边缘调整，按应用记住。
- 侧栏放不下全部文字时，分页按钮只显示图标，悬停可见名称。

## ElyTable 的公式补全

- 单元格内输入公式时，上下键选择函数候选，Tab、Enter 或单击候选接受函数并继续编辑参数。没有函数候选时，Enter 提交输入并移到下一格。
- 数据有效性的下拉按钮保留当前单元格，选择的值写入该格；点击输入说明不切换到其后被遮住的单元格。

## ElyTable 的命令行

ElyTable 开着、文件已打开时，别的程序（脚本、AI 代理）可经命令行读写其中的单元格。地址要写明工作表，如 `Sheet1!A1`；读写不动你的光标与选区，写入是一步撤销。

- `ely-table cell docs` 列出打开的已存文件。
- `ely-table cell get 文件 地址` 输出该格的地址、显示的文字与输入（公式带 `=`），为 JSON。
- `ely-table cell set 文件 地址 文字` 写入；以 `=` 开头即公式。
- `ely-table cell save 文件` 保存，输出保存到的路径。文件在磁盘上被改过时不覆盖，ElyTable 里询问。

只有同一用户在本机的程序能连上。

## ElyDoc 的命令行

ElyDoc 开着、文件已打开时，别的程序可经命令行读改其中的正文。读与替换不动你的光标与选区，一次替换是一步撤销。

- `ely-doc text docs` 列出打开的已存文件。
- `ely-doc text get 文件` 输出正文，一段一行；脚注、批注、文本框与删除的修订不在其中。
- `ely-doc text replace 文件 原文 新文` 把正文里每处原文（区分大小写、不跨段）换成新文；一处也没有即报错。
- `ely-doc text save 文件` 保存，输出保存到的路径。文件在磁盘上被改过时不覆盖，ElyDoc 里询问。

同样只有同一用户在本机的程序能连上。

## ElyShow 的命令行

ElyShow 开着、文件已打开时，别的程序可经命令行读改幻灯片上的文字。读与替换不动你所在的幻灯片与选中的对象；替换总是遍及全部幻灯片，不只选中的对象（进入组合后选着其中的对象时拒绝，先退出组合）；替换照 Impress 的全部替换，每个改到的文本框是一步撤销。

- `ely-show text docs` 列出打开的已存文件。
- `ely-show text get 文件` 输出每张幻灯片的文字，一段一行，幻灯片之间是换页符（`\f`）；备注与批注不在其中。
- `ely-show text replace 文件 原文 新文` 把幻灯片上每处原文（区分大小写、不跨段）换成新文；一处也没有即报错。
- `ely-show text save 文件` 保存，输出保存到的路径。文件在磁盘上被改过时不覆盖，ElyShow 里询问。

同样只有同一用户在本机的程序能连上。

## ElyPDF 的页面

- “视图”菜单的“横向滚动”把页面排成一行，左右滚动；Shift 加滚轮横移。
- 左栏缩略图可拖动调整页序：放在一页的上半落在它前面，下半落在它后面，拖动时一条线标出落点。落回原处不算改动。

## ElyMark 的菜单与快捷键

- 段落与格式菜单照 Typora。菜单里带 Shift 的标点键写成所出的字符，如 Ctrl+{ 即 Ctrl+Shift+[。标题：Ctrl+1 至 Ctrl+6，Ctrl+0 段落，Ctrl+= 与 Ctrl+- 升降一级。块：Ctrl+Shift+K 代码块，Ctrl+Shift+M 公式块，Ctrl+Shift+Q 引用，Ctrl+Shift+[ 有序列表，Ctrl+Shift+] 无序列表，Ctrl+Shift+X 任务列表。
- 格式：Ctrl+B 加粗，Ctrl+I 斜体，Ctrl+U 下划线，Ctrl+Shift+` 代码，Alt+Shift+5 删除线，Ctrl+K 超链接，Ctrl+Shift+I 插入图片，Ctrl+\ 清除样式。
- 表格在“段落 ▸ 表格”：Ctrl+T 插入，Ctrl+Enter 下方插入行，Ctrl+Shift+Backspace 删除行，Alt+方向键移动行列，“格式化表格源码”对齐各列。
- 视图：Ctrl+/ 在源码与编辑模式之间切换，F8 专注，F9 打字机，Ctrl+Shift+= 放大，Ctrl+Shift+- 缩小，Ctrl+Shift+0 实际大小（Windows 的中文输入法占着这个键，在 Windows 上用 Ctrl+Shift+9）；编辑、源码、预览在“视图”菜单与状态栏里选。源码模式默认显示行号（“视图›源码模式显示行号”可关）；状态栏在各模式都写出插入点所在的行与列。
- 状态栏写出全文的字数与字符数（汉字一字一数，字符含空格与标记），有选区时写出“已选 N / 总数 字”。
- 正文字体在“视图”菜单：无衬线、衬线、等宽，或“其他字体…”选任意系统字体；数字等宽。
- 文件页的最近文件可右键“从最近列表中移除”，文件本身不动。右键标签、最近文件或文件夹里的文件可“复制文件名”“复制路径”。
- 编辑：Ctrl+Shift+C 复制为 Markdown（无选区时复制全文），Ctrl+Shift+V 粘贴为纯文本；另有复制为纯文本、复制为 HTML 代码（图片保留原地址）、复制为富文本。
- 右键菜单照 Typora，随所点之处变化：剪切、复制、粘贴、删除为一行图标；链接可打开、复制地址；图片可打开所在位置（网络图片在浏览器打开）、删除；代码块可复制其内容；公式与 HTML 块可编辑；加粗、斜体、代码、超链接与引用、列表各为一行图标；表格里为“表格 ▸”，别处为“段落 ▸”；“插入 ▸”；引用、列表、代码块等可整块删除。右键落在选区里时选区保留；正在编辑的块右键后仍开着。源码模式只有剪贴板与“复制／粘贴为”，预览只有复制。
- 命令用不了时（如在代码里设标题、插入点不在表格里），提示写明原因，文字不动。macOS 上 Ctrl 为 Cmd。

## 恢复

- 有未保存改动时，每 10 秒在本机数据目录写一个恢复点（加密的文档其恢复点也加密），只留在本机，不上传。
- 应用崩溃后再启动，未保存的内容以未命名副本打开，原文件不动；只恢复内容，光标与撤销历史不恢复。
- 文档引擎单独停止时，窗口上方写明原因与最近一次恢复点的时间，“重新打开文档”起新引擎并逐个重开：有改动的从恢复点、无改动的从文件。
- 设置“存储”里可看日志、恢复副本的大小，选每个文档保留几个恢复点与多少空间，并清除它们（先问）。

## 数据文件夹

- 设置“存储”的“数据文件夹”可换位置：选一个文件夹，数据放进其中的 `ElyOffice`。下次启动 Ely 应用、且没有别的 Ely 应用开着时搬过去，旧位置随后删去。
- 所选文件夹里已有 Ely 的数据（如重装系统后）即直接使用，不搬。所选位置不在（移动盘拔了）时应用不启动，提示接上它，或删去默认位置的 `folder.json` 回到默认位置。

## 离线边界

- ElyDoc、ElyTable、ElyShow、ElyPDF、ElyTree、ElyMark 都不需要网络、账号或在线服务；启动与空闲时不连网。
- ElyMail 只连你的邮件服务器，登录 Microsoft 时另连其登录页；邮件里的网络图片不经你同意不取。系统设了代理时经代理连接（HTTP CONNECT 或 SOCKS5；PAC 不支持），环境变量 `ALL_PROXY`、`HTTPS_PROXY`、`HTTP_PROXY` 与 `NO_PROXY` 优先。
- ElyMark 不连网：文档里的网络图片不加载，HTML 不运行。本机图片照文档里写的路径读：相对路径从文档所在文件夹算起，`..`、绝对路径与 `file:` 地址可指向别处。
- ElyTree 只在你取回、拉取、推送、克隆时连网，凭据照用你的 Git 设置（credential helper、ssh-agent），Ely 不在终端问密码。
- 检查更新只在你手动检查（应用菜单或设置›通用的“立即检查”），或打开了“启动时检查更新”时进行；下载后校验 SHA-256，按“重新启动以更新”才在退出后安装：macOS 换掉 .app，Windows 运行该应用的安装程序装回原文件夹，Linux 的 AppImage 换掉原文件。deb、rpm、Arch 包只提示新版本与升级命令，由包管理器安装。开发构建不检查。

## 仓库操作（ElyTree）

- 改动页：暂存、取消暂存、按块或按行暂存，放弃改动与清理未跟踪文件每次都先问并列出会删的文件。
- 历史页：搜索提交、文件历史、逐行追溯；分支页：切换、合并、变基（先问）、标签。
- 强制推送写明会覆盖的提交，只推所示的那个提交，远端在你上次取回后变了即被拒。
- 引用日志可找回删掉的分支；“把当前分支移到此”保留工作区改动，从不做硬重置。
- 另一个 Git 正在工作时（锁文件），Ely 说明原因并可重试，从不删除锁文件。

## 邮件（ElyMail）

- 账号：Microsoft 在浏览器里登录授权；Gmail 与 iCloud 用应用专用密码（添加页的按钮打开申请页）；其他邮箱填 IMAP 或 POP3 与 SMTP。0.1.10 里用 Google 登录添加的 Gmail 账户须移除后重新添加。Outlook.com 拒绝 IMAP（“authenticated but not connected”）时，在 outlook.live.com 登录一次并完成它要求的验证，再试。密码与令牌只存在系统凭据库；凭据库不可用时只留在内存，退出即忘。
- 同步：每 10 分钟一次，也可“立即同步”。邮件头全取，正文只取近 90 天的，附件在打开或下载时才取；把文件夹设为离线保留即取整封。暂停同步不停发件箱。
- 读信：网络图片默认不载入，跟踪像素从不载入；可载入本信的图片，或总是载入某个发件人的。
- 邮件链接：ElyMail 可选作 `mailto:` 链接的邮件程序（macOS 的“邮件”设置、Windows 的“默认应用”、Linux 的桌面设置里选它），装上时从不抢为默认。点链接即开一封新信，收件人、抄送、密送、主题与正文照链接填好；正文为纯文本。链接坏了即提示，不开信。
- 写信：纯文本或 Markdown。停手即存草稿，关窗不丢。发送先进发件箱，连不上时下次同步再发。服务器已接受只说明它收下了；结果不明的邮件从不自动重发。
- 关窗后 ElyMail 留在托盘（macOS 菜单栏、Windows 通知区），同步与发送照常，从托盘退出。新邮件通知只写发件人与封数，设置“邮件”里可关。
- 迁移：账号页导入 MBOX 到本机文件夹，不上传服务器；文件夹右键导出 MBOX；邮件可另存为 EML，打开 .eml 文件即只读查看。
- 存储：设置“存储”里看邮件与索引的大小，设下载邮件的上限，清理已下载的正文（只放下服务器上仍有的）。
